TCE Admin Guide for Primary TCE Contacts

This guide covers the three main pages Primary TCE Contacts use in the TCE Admin system: the Dashboard, Verification Reports, and the Administrator List.

Open the TCE Admin site: https://facadv.uky.edu/tce-admin

Dashboard

The Dashboard is your starting point for a quick review of your college's TCE information. It summarizes the current number of courses marked for TCE, courses not marked for TCE, zero-enrollment courses, and total students based on the most recent SAP refresh.

Open the Dashboard: https://facadv.uky.edu/tce-admin

What you can do on the Dashboard

  • Review how many courses are marked for TCE.
  • Review how many courses are not marked for TCE.
  • Review how many courses currently have zero enrollment.
  • Review the total number of students in your scope.
  • Use Quick Actions to open Verification Reports or the Administrator List.
  • Confirm your current access, such as Dashboard Access, Static Report Access, and Question Bank access.

Verification Reports

The new Verification page is more responsive than the previous version and includes stronger filtering options. It lets you review both courses that are marked for TCE and courses that are not marked for TCE. It also shows the number of students in each course, pulled from SAP and refreshed daily.

Open Verification Reports: https://facadv.uky.edu/tce-admin/verification/

Search bar and standard filters

At the top of the page, use the search bar and filters to narrow the course list.

  • Search: Search by course code or course title.
  • College: Available for users with broader access. Most Primary Contacts are already scoped to one college.
  • Department: Narrow the list to a specific department.
  • Academic Term: Narrow the list to a specific term.
  • Filter: Apply the selected filters.
  • Clear: Reset the page to the full scoped list.

Quick filters

Below the main filters are quick filter buttons that make it easy to review common groups of courses.

Quick Filter Meaning
All Shows all courses within your current scope and filter selections.
Marked Shows only courses marked for TCE.
Not Marked Shows courses that are not marked for TCE.
Active Enrollment Shows courses with students enrolled.
Zero Enrollment Shows courses with zero students at the most recent SAP refresh.
Marked & Zero Enrollment Shows courses marked for TCE that currently have zero students.
Not Marked & Active Enrollment Shows courses with active enrollment that are not marked for TCE.

Direct zero-enrollment link: https://facadv.uky.edu/tce-admin/verification/?tce_status=zero_enrollment

Verification table headers

The main Verification table includes the following columns:

Header Meaning
Course The course code.
Section The section identifier for that course offering.
Instructor(s) The assigned instructors for the course.
Title The course title. Clicking the title opens the course detail page.
College The college code for the course.
Department The department connected to the course.
Course Start The instructional start date for the course.
Course End The instructional end date for the course.
TCE Start The scheduled start date for the TCE window.
Status Shows whether the course is marked, not marked, or flagged because it has zero enrollment.
Students The current student count from SAP.

Course detail page

Clicking a course title opens additional details for that course, including:

  • Course start and end dates
  • TCE start and end dates
  • Instructor names and LinkBlue IDs
  • Student count
  • Crosslisted sections, when applicable

Export CSV

The Export CSV option exports the current Verification list based on your active filters. This is useful if you need to share a filtered course list externally or save a record of what you reviewed.

Administrator List

Starting this semester, Primary TCE Contacts can modify, remove, and add administrators in Blue from the Administrator List page.

Open the Administrator List: https://facadv.uky.edu/tce-admin/admin/

What you can do on the Administrator List

  • Add a new administrator
  • Edit an existing administrator
  • Copy an existing administrator's settings to create a new one
  • Deactivate an administrator who should no longer have access
  • Filter by name, contact type, primary status, or access type

How to add an administrator

  1. Select Add Admin.
  2. Enter LinkBlue, first name, last name, and email.
  3. Select the correct Contact Type.
  4. Select the correct college and department scope.
  5. Choose whether the person is a Primary Contact.
  6. Set the access options and save the record.

How to add a Course Coordinator

  1. Select Add Admin.
  2. Choose Department as the contact type.
  3. Check the box for This is a Course Coordinator.
  4. Enter the Course Prefix.
  5. Enter the Course Number if the contact should manage one course only.
  6. Leave the course number blank if the contact should manage all courses with that prefix.
  7. Save the record.

Recommended access settings

Setting Recommendation
Level Type By default, choose Report Viewer if you do not want the contact to receive additional course emails such as course evaluation start and reminder emails. Report Viewers should receive only the email telling them reports are ready to view.
Dashboard Access Dashboard Access is for aggregate access on the new Dashboard. These licenses are limited, and extra licenses may come with a charge.
Static Report Access Static Reports are the PDF reports colleges have historically used and are not license-limited.

Daily sync timing

Administrators are synced daily at 4:00 AM. Please make changes before the end of the day if you want them included in the next morning's sync.

Question Bank note

For colleges that use the Question Bank, it is part of the same TCE Admin site. If your college has access, you will see the additional Question Bank tab in the menu. A separate how-to resource will be made available for using the Question Bank.
