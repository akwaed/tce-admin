Help
Wildcard Assignments

If you leave the course number empty, the assignment becomes a "wildcard" that matches ALL courses with the specified prefix.

Example: Prefix "UK" with no number matches UK 101, UK 102, UK 201, etc.

Multiple Assignments

A course coordinator can have multiple assignments. For example, someone could coordinate "UK 101", "BAE 201", and all "CS" courses.

DRA Export

When exporting DRA data, all matching courses will be included for each assignment. Wildcard assignments will expand to include all matching class IDs.
